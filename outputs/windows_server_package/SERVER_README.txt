Camera IP Tools: установка на Windows Server
==============================================

Требования
----------
- Windows Server 2019/2022 x64;
- серверная сетевая карта имеет адрес в VLAN камер;
- запуск установки выполняется от администратора.

Python и необходимые DLL ESC уже находятся внутри автономного комплекта.
Интернет и отдельная установка Python/ESC на сервере не нужны.

Установка
---------
1. Перенесите ZIP на сервер и распакуйте его.
2. Откройте PowerShell от имени администратора в распакованной папке.
3. Выполните:

   Set-ExecutionPolicy -Scope Process Bypass
   .\install.ps1 -ConfigureFirewall

Программа будет установлена в C:\CameraIpTools. Пароли не копируются и не
сохраняются. Автономный ZIP содержит фирменные DLL, поэтому его нельзя
публиковать в GitHub или передавать третьим лицам.

Графическая оболочка
--------------------
После установки запустите двойным щелчком или из PowerShell:

   C:\CameraIpTools\camera-gui.cmd

В окне сначала выберите или создайте объект. Для каждого объекта программа
отдельно сохраняет диапазоны, сетевые настройки, размеры таблицы и последний
список камер в файле C:\CameraIpTools\camera_tools.db. Пароли в базу не
записываются.

Один запуск поиска выполняет три прохода Sunell/ONVIF и объединяет результаты
по MAC, DeviceID или серийному номеру. Камера не удаляется из списка из-за
одного пропущенного ответа: в колонке "Ответы" видно 1/3, 2/3 или 3/3, а ранее
известные недоступные камеры остаются со статусом "не ответила".

После обнаружения в фоне читаются маска, шлюз, NTP-сервер, часовой пояс и кодек
основного потока. Для неподдерживаемых параметров таблица показывает, что
значение не прочитано. Можно сформировать диапазон назначения, выбрать число
повторных прогонов и экспортировать расширенную таблицу камер. Колонка
"Назначить" определяет, каким камерам будет отправлена команда смены IP.

Если во время сканирования логин или пароль были заданы неверно, исправьте их и
нажмите "Обновить данные". Без отметок кнопка повторно опрашивает все доступные
камеры; с отметками — только выбранные. Повторное сканирование для этого не
требуется.

Маска, шлюз, DNS, NTP и часовой пояс загружаются из camera_config.yaml и могут
быть изменены в окне перед запуском. Изменения в полях окна не перезаписывают
YAML автоматически.

Общие логин и пароль также задаются в окне. После поиска программа автоматически
назначает профили: Sunell — cross, модели S8 — apix_s8, остальные ONVIF-модели —
apix_e8. Для камер с отдельными паролями используйте отдельный запуск или запись
для конкретного IP в camera_config.yaml, чтобы не блокировать учётную запись.

Сначала выполните сканирование и проверьте сформированный план. Реальная смена
IP выполняется только кнопкой "Назначить IP" после отдельного подтверждения.

Несколько камер с адресом 192.168.0.250
---------------------------------------
1. Укажите диапазон 192.168.0.250–192.168.0.250 и выполните сканирование либо
   включите "Поиск производителя".
2. Отметьте найденные камеры и задайте диапазон новых адресов.
3. Нажмите "Сформировать план" и проверьте пары MAC → новый IP.
4. Нажмите "Дефолтный IP".

Этот режим работает только с камерами Sunell/Evidence, которые фирменный поиск
обнаружил с MAC и DeviceID. Перед первой командой программа проверяет, что весь
пул свободен и выбранные камеры еще находятся на исходном адресе. Затем она
последовательно отправляет адресную команду через фирменный SDK, сбрасывает ARP
и подтверждает тот же MAC/DeviceID на новом IP. При первой ошибке дальнейшая
обработка останавливается. Результат сохраняется в
C:\CameraIpTools\default_ip_assignment_results.csv.

Проверка поиска
---------------
Подставьте IP сетевой карты сервера, подключенной к сети камер:

   C:\CameraIpTools\camera-tool.cmd scan --interface-ip 10.53.240.253 --timeout 6

Результат:
   C:\CameraIpTools\vendor_camera_inventory.csv

Один запуск выполняет multicast-поиск Sunell/Evidence, ONVIF и все шесть
фирменных методов ESC: Milesight, TopView, Hunt, Sunell, UNV и DynaColor.
В конце выводится количество камер по каждому протоколу.

В графической программе при сканировании заданного IP-диапазона сначала
проверяется ping/HTTP. Если фирменный поиск не вернул ответивший адрес, программа
делает прямой авторизованный ONVIF-запрос. В таблицу добавляются только устройства,
подтвердившие GetDeviceInformation, поэтому обычные серверы и коммутаторы по одному
ping камерами не считаются.

Если список пустой
------------------
- проверьте, что сервер действительно подключен к тому же VLAN;
- проверьте входящие UDP 31002 и 6667 в брандмауэре;
- укажите правильный адрес карты через --interface-ip;
- multicast 234.5.6.7 не должен блокироваться виртуальным коммутатором или VLAN.

Фирменный поиск запускается из python.exe/pythonw.exe и VendorBridge.exe, поэтому
правило, разрешающее только ESC.exe, для него не подходит. Устанавливайте пакет
из PowerShell от имени администратора с параметром -ConfigureFirewall: установщик
создаст правила портов и правила для этих трёх программ.

Формирование плана
------------------
Пример:

   C:\CameraIpTools\camera-tool.cmd assign --start-ip 10.53.240.30 --end-ip 10.53.240.176 --mask 255.255.252.0 --gateway 10.53.240.1 --dns 10.70.200.5

Перед применением откройте C:\CameraIpTools\vendor_camera_plan.csv и проверьте
колонки selected и new_ip.

Проверка без изменения камер
----------------------------

   C:\CameraIpTools\camera-tool.cmd apply --username Admin

Реальное применение
-------------------
Сначала обработайте одну выбранную строку, только затем весь список:

   C:\CameraIpTools\camera-tool.cmd apply --username Admin --workers 3 --verify-seconds 30 --apply

Пароль запрашивается в консоли и в CSV не записывается. Результат сохраняется в
C:\CameraIpTools\vendor_camera_results.csv.

Примечание
----------
Это консольная серверная версия. Она не требует постоянно работающей службы.
Веб-интерфейс можно добавить отдельным этапом поверх проверенного серверного ядра.

Проверка текущих NTP и часового пояса
-------------------------------------
Команда только читает настройки и использует уже созданный список камер:

   C:\CameraIpTools\camera-tool.cmd audit-time --credential Admin:PASSWORD --credential-for 10.53.240.123-10.53.240.125=admin:OTHER_PASSWORD

Результат:
   C:\CameraIpTools\camera_time_audit.csv

Для адресов из --credential-for основная учётная запись не проверяется. Это
уменьшает риск блокировки пользователя из-за неправильного пароля.

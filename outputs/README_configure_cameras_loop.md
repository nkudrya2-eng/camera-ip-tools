# Настройка IP камер из пула

Скрипт: `configure_cameras_loop.py`

## Что делает

Скрипт ждет камеру на временном адресе `192.168.0.250`, проверяет свободен ли следующий IP из пула, отправляет камере команду смены сетевых настроек, чистит ARP и ждет следующую камеру.

Работает по кругу, пока:

- не закончится пул IP;
- новая камера не появится за время `--empty-timeout`;
- камера не вернет ошибку.

## Рекомендуемый запуск

Открой PowerShell от имени администратора и запусти:

```powershell
py -3 "C:\Users\n.kudrya\Documents\Codex\2026-06-25\new-chat\outputs\configure_cameras_loop.py" --username Admin --start-ip 10.53.240.84 --end-ip 10.53.240.254 --gateway 10.53.240.1 --empty-timeout 120
```

После запуска скрипт спросит пароль.

## Основные параметры

- `--camera-ip 192.168.0.250` - адрес, на котором скрипт ищет новую камеру.
- `--start-ip 10.53.240.84` - первый IP из пула.
- `--end-ip 10.53.240.254` - последний IP из пула.
- `--gateway 10.53.240.1` - шлюз, который будет записан в камеру.
- `--netmask 255.255.255.0` - маска сети.
- `--username Admin` - пользователь камеры.
- `--empty-timeout 120` - остановиться, если новая камера не появилась за 120 секунд.

## Как идет работа

1. Подключи камеру с адресом `192.168.0.250`.
2. Скрипт найдет ее и назначит первый свободный IP из пула.
3. После сообщения `Succeed` отключи настроенную камеру.
4. Подключи следующую камеру.
5. Скрипт продолжит со следующим свободным IP.

## Проверка свободного IP

Перед назначением каждого адреса скрипт чистит ARP и пингует целевой IP.

Если адрес занят, будет сообщение:

```text
Skipping 10.53.240.84: address is already in use.
```

После этого скрипт возьмет следующий адрес из пула.

Если проверку нужно отключить:

```powershell
--no-free-check
```

## Ошибки

`UserLocked` - пользователь камеры заблокирован. Останови скрипт, подожди разблокировки или проверь пароль.

`Command failed; stopping to avoid repeated login attempts.` - камера вернула ошибку, скрипт остановился, чтобы не заблокировать пользователя повторными попытками.

`Could not clear ARP cache` - PowerShell запущен не от администратора. Запусти терминал от имени администратора.

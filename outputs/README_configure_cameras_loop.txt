Настройка IP камер из пула

Скрипт: configure_cameras_loop.py

Что делает

Скрипт ждет камеру на временном адресе 192.168.0.250, проверяет свободен ли следующий IP из пула, записывает NTP, отправляет камере команду смены сетевых настроек, чистит ARP и ждет следующую камеру.

Перед сменой IP скрипт пытается прочитать с камеры:
- модель;
- серийный номер;
- MAC;
- версию прошивки;
- настройки сетевого интерфейса;
- настройки видеопотоков.

Эти данные сохраняются в файл camera_inventory.csv рядом со скриптом.

Работает по кругу, пока:
- не закончится пул IP;
- новая камера не появится за время --empty-timeout;
- камера не вернет ошибку.

Рекомендуемый запуск

Открой PowerShell от имени администратора и запусти:

py -3 "C:\Users\n.kudrya\Documents\Codex\2026-06-25\new-chat\outputs\configure_cameras_loop.py" --username Admin --start-ip 10.53.240.84 --end-ip 10.53.240.254 --gateway 10.53.240.1 --empty-timeout 120

После запуска скрипт спросит пароль.

Основные параметры

--camera-ip 192.168.0.250
Адрес, на котором скрипт ищет новую камеру.

--start-ip 10.53.240.84
Первый IP из пула.

--end-ip 10.53.240.254
Последний IP из пула.

--gateway 10.53.240.1
Шлюз, который будет записан в камеру.

--ntp-server 10.53.240.12
NTP-сервер, который будет записан в камеру перед сменой IP.

--ntp-port 123
Порт NTP.

--ntp-interval-minutes 60
Интервал проверки времени. Для Sunell в камеру уходит 3600 секунд.

--no-ntp
Не записывать NTP перед сменой IP.

--netmask 255.255.255.0
Маска сети.

--username Admin
Пользователь камеры.

--empty-timeout 120
Остановиться, если новая камера не появилась за 120 секунд.

--api-retries 3
Сколько раз сбрасывать ARP и повторять HTTP-проверку API камеры.

--api-retry-seconds 1
Пауза после сброса ARP перед повторной HTTP-проверкой.

--log-file путь_к_файлу.csv
Куда сохранять данные камер. По умолчанию: camera_inventory.csv рядом со скриптом.

Как идет работа

1. Подключи камеру с адресом 192.168.0.250.
2. Скрипт найдет ее, запишет NTP и назначит первый свободный IP из пула.
3. После сообщения Succeed отключи настроенную камеру.
4. Подключи следующую камеру.
5. Скрипт продолжит со следующим свободным IP.

Проверка свободного IP

Перед назначением каждого адреса скрипт чистит ARP и пингует целевой IP.

После обнаружения камеры на 192.168.0.250 скрипт также чистит ARP перед HTTP-опросом камеры. Это нужно, когда несколько камер по очереди появляются на одном и том же временном IP.

Если адрес занят, будет сообщение:

Skipping 10.53.240.84: address is already in use.

После этого скрипт возьмет следующий адрес из пула.

Если проверку нужно отключить, добавь к запуску:

--no-free-check

Журнал камер

Файл camera_inventory.csv содержит:
- source_ip - временный адрес камеры;
- assigned_ip - назначенный адрес из пула;
- model - модель;
- serial_number - серийный номер;
- mac - MAC-адрес;
- firmware - версия прошивки;
- video_streams_json - сырые настройки видеопотоков, если камера их отдала;
- channels_json - сырые данные каналов, если камера их отдала;
- device_info_json - полный ответ с информацией об устройстве;
- network_json - полный ответ по сетевым интерфейсам.

Сбор информации после настройки

После массовой смены IP можно отдельно пройтись по новым адресам и собрать данные уже с назначенных IP.

Скрипт: collect_camera_info.py

Вариант 1. Сбор по диапазону:

py -3 "C:\Users\n.kudrya\Documents\Codex\2026-06-25\new-chat\outputs\collect_camera_info.py" --username Admin --start-ip 10.53.240.84 --end-ip 10.53.240.254

Вариант 2. Сбор по IP из camera_inventory.csv:

py -3 "C:\Users\n.kudrya\Documents\Codex\2026-06-25\new-chat\outputs\collect_camera_info.py" --username Admin --input-csv "C:\Users\n.kudrya\Documents\Codex\2026-06-25\new-chat\outputs\camera_inventory.csv"

Результат по умолчанию сохраняется в файл:

C:\Users\n.kudrya\Documents\Codex\2026-06-25\new-chat\outputs\camera_info_after.csv

Если камера не отвечает на ping, скрипт ее пропускает. Если ping отключен на камерах, добавь:

--skip-ping

Проверка доступных LAPI endpoint-ов

Если нужно понять, какие LAPI-запросы реально поддерживает камера, используй:

probe_lapi_endpoints.py

Проверить одну камеру:

py -3 "C:\Users\n.kudrya\Documents\Codex\2026-06-25\new-chat\outputs\probe_lapi_endpoints.py" --username Admin --ip 10.53.240.30

Проверить пул:

py -3 "C:\Users\n.kudrya\Documents\Codex\2026-06-25\new-chat\outputs\probe_lapi_endpoints.py" --username Admin --start-ip 10.53.240.30 --end-ip 10.53.240.86

Результат сохраняется в:

C:\Users\n.kudrya\Documents\Codex\2026-06-25\new-chat\outputs\lapi_probe.csv

В CSV будут статусы по каждому endpoint-у: 200, 404, 401, ошибка соединения и короткий фрагмент ответа.

Ошибки

UserLocked
Пользователь камеры заблокирован. Останови скрипт, подожди разблокировки или проверь пароль.

Command failed; stopping to avoid repeated login attempts.
Камера вернула ошибку, скрипт остановился, чтобы не заблокировать пользователя повторными попытками.

Could not clear ARP cache
PowerShell запущен не от администратора. Запусти терминал от имени администратора.

Один тестовый запуск

Чтобы настроить только одну камеру и выйти:

py -3 "C:\Users\n.kudrya\Documents\Codex\2026-06-25\new-chat\outputs\configure_cameras_loop.py" --username Admin --start-ip 10.53.240.84 --end-ip 10.53.240.84 --gateway 10.53.240.1 --once

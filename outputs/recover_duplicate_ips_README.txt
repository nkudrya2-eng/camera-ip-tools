Поиск и восстановление камер с задублированным IP
=================================================

Скрипт:
  recover_duplicate_ips.py

Что делает:
  1. Берет очередной IP из диапазона проверки.
  2. Переносит найденную камеру на временный IP своего потока.
  3. Проверяет, продолжает ли отвечать исходный IP.
  4. Если исходный IP продолжает отвечать, значит за ним был дубль.
  5. Найденную камеру оставляет не на временном IP, а переносит в пул 10.53.240.145-149.
  6. При опасной ошибке останавливает дальнейшую обработку.

По умолчанию:
  Диапазон проверки: 10.53.240.30-176
  Пул восстановления: 10.53.240.145-149
  Временные пулы потоков:
    поток 1: 10.53.240.180-189
    поток 2: 10.53.240.190-199
    поток 3: 10.53.240.200-210

Обычный запуск:
  py -3 "C:\Users\n.kudrya\Documents\Codex\2026-06-25\new-chat\outputs\recover_duplicate_ips.py" --credential Admin:ПАРОЛЬ1 --credential admin:ПАРОЛЬ2

Что будет в консоли:
  По обычным IP почти ничего.
  Если дубль найден:
    ДУБЛЬ НАЙДЕН: 10.53.240.X -> 10.53.240.145 (duplicate_recovered)

Подробный режим:
  Добавить --verbose

Лог:
  outputs\duplicate_ip_recovery.csv

Важно:
  Запускать из PowerShell от имени администратора, иначе arp -d может не сработать.
  Скрипт специально пропускает IP 10.53.240.145-149 как исходные адреса, чтобы не трогать пул восстановления.
  Не используйте этот скрипт, если временные пулы уже заняты.
  После строки "ПРОВЕРЬ" продолжать нельзя: сначала восстановить адреса по CSV-логу.

Автоматически заполнить диапазон камер
======================================

Задача:
- камеры должны быть в диапазоне 10.53.240.30-55;
- адрес 10.53.240.30 уже есть;
- скрипт ищет первую свободную "дырку" в 30-55;
- потом ищет камеру вне диапазона, начиная с 10.53.240.56;
- назначает найденной камере свободный адрес из 30-55;
- делает до 3 назначений одновременно;
- ждет 15 секунд перед повторным сканом;
- снова сканирует сеть и повторяет.

Команда:
py -3 "C:\Users\n.kudrya\Documents\Codex\2026-06-25\new-chat\outputs\auto_fill_camera_range.py" --credential Admin:ПАРОЛЬ --credential admin:ПАРОЛЬ

Если нужно явно:
py -3 "C:\Users\n.kudrya\Documents\Codex\2026-06-25\new-chat\outputs\auto_fill_camera_range.py" --target-range 10.53.240.30-55 --source-range 10.53.240.56-240 --credential Admin:ПАРОЛЬ --credential admin:ПАРОЛЬ

Если нужно сканировать только конкретные IP, а не весь диапазон:
py -3 "C:\Users\n.kudrya\Documents\Codex\2026-06-25\new-chat\outputs\auto_fill_camera_range.py" --target-range 10.53.240.73-85 --source-ips 10.53.240.54,10.53.240.56,10.53.240.182 --credential Admin:ПАРОЛЬ --credential admin:ПАРОЛЬ

Количество потоков:
  По умолчанию --workers 3
  Чтобы временно сделать медленно и по одной камере: --workers 1
  Для отдельного числа потоков команд: --command-workers 12

Режим залпа за один проход:
py -3 "C:\Users\n.kudrya\Documents\Codex\2026-06-25\new-chat\outputs\auto_fill_camera_range.py" --salvo --target-range 10.53.240.120-140 --source-ips 10.53.240.110,10.53.240.112 --command-workers 12 --credential Admin:ПАРОЛЬ --credential admin:ПАРОЛЬ

Что делает --salvo:
  1. Один раз сканирует целевой диапазон.
  2. Один раз сканирует источники.
  3. Печатает матрицу source -> target.
  4. Отправляет все команды параллельно.
  5. Ждет cooldown и делает контрольный скан.

Важно:
- не использует временные IP;
- перед каждой сменой еще раз проверяет, что целевой IP свободен;
- если source-range пересекается с target-range, целевые IP не используются как источники;
- если указан --source-ips, сканируется только этот список, source-range игнорируется;
- после отправки команд делает паузу 15 секунд и сканирует заново;
- по умолчанию не ждет появления каждой камеры сразу после смены, чтобы не терять время;
- если нужна строгая проверка сразу после каждой смены, добавить --verify-after-change;
- если смена IP не подтверждена, останавливается;
- если камера не приняла API/пароль, пишет change_failed, пропускает ее и пробует следующую;
- если в 30-55 нет свободных адресов, завершает работу;
- если есть свободный адрес, но после 56 камер не найдено, завершает работу.

Полевое назначение IP по одной камере
=====================================

Сценарий:
1. Отключить все камеры от сети.
2. Подключить только одну камеру.
3. Скрипт найдет единственный отвечающий IP в диапазоне сканирования.
4. Скрипт назначит следующий IP из заданного пула.
5. После OK отключить эту камеру и подключить следующую.

По умолчанию:
- сканирование: 10.53.240.30-240
- назначаемые IP: 10.53.240.145-149
- маска: 255.255.252.0
- шлюз: 10.53.240.1
- DNS: 10.70.200.5, 10.70.200.6

Команда:
py -3 "C:\Users\n.kudrya\Documents\Codex\2026-06-25\new-chat\outputs\field_assign_cameras.py" --credential Admin:ПАРОЛЬ --credential admin:ПАРОЛЬ

Если нужен другой пул:
py -3 "C:\Users\n.kudrya\Documents\Codex\2026-06-25\new-chat\outputs\field_assign_cameras.py" --target-range 10.53.240.145-149 --scan-range 10.53.240.30-240 --credential Admin:ПАРОЛЬ --credential admin:ПАРОЛЬ

Поведение защиты:
- если камер не видно, скрипт ждет;
- если видно больше одной камеры, скрипт ничего не меняет;
- если назначаемый IP уже занят, скрипт останавливается;
- если камера не появилась на новом IP, скрипт останавливается;
- никаких временных адресов 180-210 не используется.

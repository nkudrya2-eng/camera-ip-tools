Версия 2026.09.2 — назначение дефолтного IP
=========================================
При назначении с 192.168.0.250 программа перебирает поддерживаемые HTTP-методы:
CROSS/WEB, APIX E8/LAPI, APIX S8/CGI. Для распознанных моделей E8 и S8 сначала
проверяется соответствующий метод. При наличии обнаруженного Sunell MAC/DeviceID
доступен также фирменный метод. ONVIF-доступ к времени не считается подтверждением
возможности смены IP через LAPI/CGI.

Проверка адресного пула выполняется до 8 адресов одновременно, со счётчиком
и полосой прогресса. Занятые адреса пропускаются. Проверка повторяется непосредственно
перед отправкой; если адрес успел стать занят, программа переходит к следующему.
Адреса за пределами заданного пула не используются.

Кнопка «Остановить» останавливает проверку/назначение после текущего запроса.
Если команда смены IP уже отправлена, сначала завершается проверка нового адреса.
При потере ответа на запись (сброс соединения/тайм-аут) программа проверяет новый IP,
а не отправляет следующую команду другой камере с тем же исходным адресом.

Пропущенные адреса записываются в default_ip_assignment_results.csv со статусом
skipped_occupied. Итоговое сообщение содержит число пропущенных адресов.
Проверка доступности нового IP по-прежнему не гарантирует соответствия MAC:
несколько разных камер могут одновременно иметь исходный IP 192.168.0.250.
